# MBZUAI portfolio summary

GL Guardian explores whether adversarial multi-agent reasoning, retrieval, and verification improve
audit-risk screening over rules and a single LLM. The system combines production engineering with a
new frozen, balanced, privacy-safe synthetic benchmark; normalized method outputs; ablation configs;
classification, calibration, cost, latency, evidence-quality, uncertainty, and failure analysis;
and explicit responsible-AI controls.

The multi-agent design separates evidence collection, skeptical challenge, legitimate defense,
adjudication, and grounding verification so each role can be ablated and audited. The verified rule
result is generated from repository code. Single-LLM, full-crew, ablation, and human agreement
results remain Not run, which is the central current limitation. Lessons include the danger of
headline F1 on imbalanced synthetic data, the difference between observability proxies and research
metrics, and the need for paired, label-blind evaluation.

Future graduate research should study calibrated selective prediction, judge-human agreement,
retrieval robustness, debate dynamics, distribution shift, and utility-aware cost/quality tradeoffs.
